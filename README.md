A hand-drawn newspaper front page that sums up Tuesday 17 November 2026 in a single 1024x1024 image. Six stories, one day:

- **Middle East (hero) — Gulf on fire:** Iran fires drones at the US radar base in Bahrain; a fourth tanker is hit by a mine in the Strait of Hormuz in under 24 hours; a third US carrier sails in.
- **Europe — Bridge war:** Ukraine badly damages the Kerch bridge; Russian missiles hit Kyiv's bridges; 1,336 drones intercepted.
- **Asia — Summit:** Trump flies to APEC in Shenzhen; nuclear talks with Xi and Putin set for 19 November.
- **Tech — Chip curbs:** the US shuts the AI chip loophole; Singapore seeks trusted chip access.
- **Migration — Rwanda hub:** five EU states plan a return hub in Rwanda for rejected asylum seekers.
- **US finance — Chase bug freezes Zelle:** a JPMorgan software bug slows online banking and Zelle across the US; not a cyberattack.

Everything in the picture is drawn by the program itself — a crimson masthead with a hand-drawn globe, a Gulf scene with a carrier, a tanker, drones and a naval mine, four story cards with coloured spine bars, and a ticker strip. The lettering is a hand-built 5x7 pixel font. No photos, no network, no downloaded images, no clock, no randomness: the same bytes come out of every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes `out/entry.png` (1024x1024 PNG, about 21 KB). The program needs only the Python standard library, and with no `MAKEFUN_OUTPUT_DIR` set it writes to `/output/entry.png`, as the grader expects.

The news wording is paraphrased from the sources listed in `news-sources.md`.
