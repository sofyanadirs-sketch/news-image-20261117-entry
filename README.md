One Day on Earth — a 1024x1024 newspaper front page summing up Tuesday 17 November 2026 in one image: the Gulf on fire, a bridge war in Ukraine, a Trump–Xi–Putin summit in Asia, AI chip curbs, a Rwanda return hub, and a Chase banking bug. Drawn entirely by a pure-stdlib Python program — no photos, no network, no downloaded images.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024x1024, ~19 KB). In the grader it writes to `/output/entry.png`.
